# 胶片管理网站 — 任务规划

> 版本：v1.0
> 最后更新：2026-11-07

## 1. 里程碑总览

| 阶段 | 主题 | 交付物 | 验收标准 |
|---|---|---|---|
| M0 | 工程骨架 | monorepo、Drizzle schema、码表 seed、登录、Docker 骨架 | `pnpm dev` 跑起来，登录后可访问空首页 |
| M1 | 编号体系 | 编号解析模块 + 单测、胶卷库 CRUD、条码绑定 | 输入 `KG2T004` 能识别出 Kodak Gold 200 135 |
| M2 | 建档 | 单卷/批量建档、冲突处理、标签打印 | 一盒 5 卷 10 秒内建完，能打印标签 |
| M3 | 进度记录 | 首页、记一笔抽屉、进度快照 API、时间线 | 手机上两步完成一次记录（含回填时间） |
| M4 | 完整闭环 | 详情页、单张注解、拍完/冲洗、检索 | 单卷全生命周期可查 |
| M5 | 上线 | 统计、备份、Docker 部署、PWA | 服务器 HTTPS 可访问，手机可扫码 |

## 2. 详细任务拆解

### M0 — 工程骨架

- [ ] 创建 monorepo：`pnpm-workspace.yaml`（`server` / `web` / `shared`）
- [ ] `shared`：Zod schema、TS 类型、码表常量（品牌/系列/画幅/ISO 码）
- [ ] `server`：Fastify 启动、配置加载（`.env`）、日志
- [ ] `server/src/db`：Drizzle schema 全表定义、migration 生成、`seed` 脚本
- [ ] 码表 seed 数据：品牌、系列、ISO 码（含例外码）、画幅
- [ ] 单用户鉴权：PIN 登录 → HttpOnly Cookie
- [ ] `web`：Vue 3 + Vite + Tailwind + 路由 + Pinia 骨架
- [ ] 根目录 `docker-compose.yml` + `Dockerfile` + `Caddyfile` 骨架
- [ ] `README.md`、`.gitignore`、`.editorconfig`
- [ ] 首次 commit

**验收**：`pnpm dev` 前后端同时启动，登录后进入空首页；`pnpm db:seed` 后码表可查。

---

### M1 — 编号体系（地基，必须先做）

- [ ] `server/src/codebook/roll-code.ts`：`parseRollCode()`、`buildRollCode()`
- [ ] ISO 码双向映射（数字 1–9 / A–Z / 小写例外 a–f）
- [ ] 序列号补零与超 999 升位逻辑
- [ ] **单元测试**（Vitest）：
  - [ ] `KG2T001` → Kodak Gold 200 135 #1
  - [ ] `KG2M002` → Kodak Gold 200 120 #2
  - [ ] `KPdT010` → Portra 160 135 #10
  - [ ] `KG2T1000` → 4 位序号
  - [ ] 非法输入、未知前缀、空串、大小写混输
- [ ] `film_stock` 前后端页面：列表、新建（前缀自动拼装+校验）、编辑
- [ ] `stock_barcode` 绑定：扫码后在胶卷库中匹配型号
- [ ] `POST /api/scan` 分流逻辑（胶卷编号 / 包装条码 / 无法识别）
- [ ] CSV 导入导出

**验收**：输入任意合法编号能定位到型号；未知前缀给出明确引导。

- [ ] 二维码标签生成与打印（QR + 编号文本）

  - [ ] 「记一笔」主按钮

## 3. 开发顺序说明

1. **M0 必须先做**，因为码表 seed 是 M1 的输入。
2. **M1 是地基**，编号解析一旦有 bug，建档数据全部污染，因此必须先写单测再写页面。
3. **M3 是价值核心**，如果时间紧，可以把 M4 的冲洗、归档部分延后。
4. M2 与 M3 可以并行，但需要先有 M1 的型号库。

## 4. 技术风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| iOS/鸿蒙扫码兼容性 | 无法扫码 | 一开始就用 `barcode-detector` WASM polyfill，不做原生依赖；M2 首日即三端实测 |
| 没有 HTTPS 导致摄像头不可用 | 扫码功能失效 | 开发用 `localhost`，生产用 Caddy 自动证书 |
| 编号规则未来扩展（新品牌/新格式） | 需要迁移 | 码表独立成表，不硬编码；前缀唯一索引留扩展空间 |
| SQLite 并发写入 | 单用户场景几乎不会发生 | 开启 WAL；写入走单进程 |
| 折叠屏布局 | 内容被拉伸 | Tailwind 断点，卡片限宽 `max-w-*` |
