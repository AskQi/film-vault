# film-vault · 胶片管理

个人胶片（胶卷）管理网站。单用户、移动优先、部署在自有服务器。

## 一句话概括

用有语义的编号（如 `KG2T001`）管理胶卷，扫码建档、批量录入，拍完快速记一笔「拍到第几张」，随手查。

## 技术栈

- 前端：Vue 3 + TypeScript + Vite + Pinia + Tailwind + PWA
- 后端：Node 22 + Fastify + Zod + Drizzle ORM
- 数据库：SQLite（WAL）
- 部署：Docker Compose + Caddy（自动 HTTPS）
